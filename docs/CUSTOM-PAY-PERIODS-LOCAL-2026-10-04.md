# Custom company pay periods and compact Time approval

Local branch codex/custom-pay-periods, based on published main 540b3ab89efc579a56f4d8392f0c9a0bde7aba91. The released Sunday schedule code is retained. No push, merge or deployment of this feature has occurred.

## Navigation and behavior

More tools → Company settings → Pay periods → New custom period. Owner/admin with manageTime can create explicit inclusive start/end dates and edit uncaptured periods with an audited reason. Each period captures its company timezone. Other companies have independent dates; no weekly/biweekly cycle, wages, tax or overtime calculation is added. Company settings tabs are Company, Pay periods, Forms & safety, Activity, showing only role/feature-authorized content with keyboard tab navigation and 44px mobile controls. Existing company profile/logo/pricing/defaults, template and activity behavior is preserved.

Time → Time-card approval → Company pay period, or Review time in Settings. Manage pay periods links back to the Settings tab. Time lists one compact row per person with total hours, complete submitted count needing approval, draft/approved/running/incomplete indicators. Selecting a person drills into only that person's entries and existing correction, submit, approve, delete and history actions. Back/search/filter/context changes clear selection. Bulk approval never starts from the person summary and can select only complete submitted entries. Optional filters and help collapse; dates/search remain visible.

Period summary reports company approved hours (PM sees assigned time only), review counts and missing scheduled people/dates/jobs. End period & export requires no running, unapproved, invalid/undated or missing scheduled entries. Missing time is detected against saved assignments only, not an invented expected workweek. Full overnight entries belong to their clock-in date in the captured timezone; both boundaries are included. Captured dates and CSV snapshots are fixed. Corrections retain prior versions, reference the latest export and require a reason. Older versions remain downloadable. Summary source hashes flag approved-time changes.

## Implementation

pay-periods.js: strict date/offset validation, overlap/config audit, review summary, immutable export lineage, safe deterministic CSV. server.js: request-scoped APIs and role gates, incomplete single/bulk approval rejection, private period/export state exclusion and no-time-admin state/audit filtering. time-approval-controls.js: compact person list/drill-down, period controls/forms/history/downloads, identity/sequence guards. company-settings-tabs.js: permission-aware tabs and discovery. index.html/styles.css/public-file-policy.js: markup/cache/mobile controls and public UI assets; server module remains private. package.json includes both new tests and syntax checks.
